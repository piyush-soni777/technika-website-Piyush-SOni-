# technika-website-Piyush-SOni

**Achieving Harmony Through Innovation**
Technika 6.0 is an interactive college fest website designed to showcase the journey, events, memories and achievements of Technika from 1.0 to 6.0.
The website combines creative animations, interactive elements and a digital platform to make the fest experience more engaging.
## 📸 Campus Lens – Our Real-Life Solution
> **The Problem:** Colleges often struggle to collect quality photographs from different events in one place.
> **Our Solution:** Campus Lens provides a shared platform where students can upload fest photographs, while admins can review, manage and shortlist the best pictures for college magazines, newspapers, social media and promotions.

## ✨ Features

- **Technika Timeline:** Showcases the journey from Technika 1.0 to 6.0.
- **Interactive Photo Frames:** Scroll-based visual storytelling with video effects.
- **Event Tree:** Displays events as hanging leaves on a tree.
- **Hall of Memories:** Presents memorable fest photographs in a creative burnt-paper theme.
- **Rewards Section:** Interactive trophies and medals with drag-and-swing animations.
- **Campus Lens:** A photo-sharing platform where students can upload fest photographs for admin review and selection.
- **Digital Registration:** Online registration with QR-based gate passes.

## 🚀 How to Run Locally

**Frontend:**

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

**Backend:**

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Backend API documentation: `/docs`

*Note: Run frontend and backend separately. Backend commands assume the entry file is `main.py`.*
